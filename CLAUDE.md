## Architecture

Single-page React 19 app with React Router 7, Tailwind CSS v4, and shadcn/ui. State is persisted exclusively in `localStorage` — there is no backend.

**Routing** (`src/App.tsx`): All routes share `LayoutMain` (sidebar + outlet). Current routes: `/` → `PageHome`, `/health` → `PageHealth`.

**State management** (`src/hooks/use-medicine.tsx`): The `useMedicine` hook wraps `useLocalStorage` (from `usehooks-ts`) on the `"medicines"` key. All CRUD for medicines and doses lives here. Components call this hook directly — there is no global store or context.

**Data model** (`src/models/medicine.tsx`): A `Medicine` has an `id`, `name`, `unit`, `basedAmounts[]`, and `doses: Dose[]`. A `Dose` is `{ usedDate: Date, amount: number }`. Dates stored in localStorage are serialized strings and must be re-wrapped with `new Date()` when read back.

**Component layers**:
- `src/components/` — generic, reusable primitives (`Container`, `Icon`, and shadcn `ui/` components). `src/components/ui/` is excluded from biome linting (generated by shadcn).
- `src/core-components/` — feature-specific composites (medicine dose grid, sidebar parts). These import from `hooks/` and `models/`.
- `src/pages/` — route-level components. `layout-main.tsx` wraps everything in `SidebarProvider`.

**Icons** (`src/components/icon.tsx`): SVGs from `src/assets/icons/` are imported via `vite-plugin-svgr` and rendered through the `Icon` component wrapper which accepts a `svg` prop (the React SVG component) and an optional `animate` variant.

**Styling**: Tailwind v4 via `@tailwindcss/vite`. Theme tokens are defined in `src/index.css` using `@theme inline`. Geist Variable is the app font. Use `cn()` from `src/lib/utils.ts` for conditional class merging.

**Path alias**: `@/` maps to `src/`.
